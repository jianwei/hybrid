# Rspress 规则

仅在新建、维护、评审或排查 Rspress 文档站时应用。规则覆盖项目中的文档站，不受 H5、RN 或其他业务平台限制。

## 读取入口

开始任务时读取[最佳实践](../../.agents/skills/rspress-best-practices/SKILL.md)，并按任务读取下表对应的本地 skill 及其相关参考文件：

| 任务 | 必须读取 |
| --- | --- |
| 新建站点、维护功能文档或排查版本兼容 | [文档生成](../../.agents/skills/rspress-docs-generator/SKILL.md) |
| 修改主题、布局、图标或全局组件 | [主题定制](../../.agents/skills/rspress-custom-theme/SKILL.md) |
| 新增页面、补全摘要或修改页面摘要 | [摘要生成](../../.agents/skills/rspress-description-generator/SKILL.md) |

## 项目适配

- 这些 skill 面向 Rspress v2。先检查实际依赖、导入路径和配置；遇到 v1 标记时评估任务是否涉及迁移，按已授权范围处理。完整迁移使用实际可用的升级 skill，缺失时实时读取官方迁移指南。
- 定位文档根目录时，同时检查配置中的 `root`、项目脚本及 CI 中的 CLI 目录参数和命令工作目录，确认实际解析结果后再扫描；默认目录与其他候选目录只作为定位线索。
- 选用配置、主题或插件 API 前，实时读取 [Rspress 官方文档索引](https://rspress.rs/llms.txt)及相关章节，并以已安装版本的公开类型或实现确认能力。保留本地 skill 作为操作参考，官方文档在线查阅。
- 新建站点沿用项目包管理器、工作区与脚本约定；构建输出配置为根目录 `dist/<文档站交付目标>/`，缓存遵循项目约定，避免覆盖其他目标。按实际 Node 要求更新软件要求。

## 主题与内容

- 遵循 [UI 定制规则](ui-customization.md)；Rspress 主题优先使用配置、CSS 变量、局部样式和 Layout 插槽，确认无法满足需求后再替换或 eject 组件。
- 在 `theme/` 内导入原主题运行组件时使用 `@rspress/core/theme-original`，保留需要的原主题导出；类型导入按实际版本的公开导出核对。运行时 hooks 按公开 runtime API 使用。
- 遵循 [文档维护规则](documentation.md)；Rspress 独立页面添加或维护 `title` 与 `description`，共享片段和生成目录不作为独立页面批量补全。
- 摘要补全保留有效的已有摘要；内容修改时检查是否需要更新。首页摘要结合 hero 与 features；摘要长度以准确、简洁为准，skill 的 50–160 字符建议不作为硬性门槛。包含 YAML 特殊字符时采用合法引号与转义，并检查解析结果。
- 导航按现有配置与实际自动导航机制维护；需要显式控制顺序或标签时使用对应版本支持的 `_nav.json`、`_meta.json`。多语言站点核验语言目录与配置，说明本次更新覆盖的语言。

## 交付检查

- 运行实际文档构建，并检查受影响页面的链接、导航、资源路径、frontmatter 与 MDX 导入；主题变化还需实际预览受影响页面。
- 开发服务验证使用可终止的进程，确认结果后清理本次启动的服务。交付说明实际验证范围及未解决的问题。
