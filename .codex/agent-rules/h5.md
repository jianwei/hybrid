# H5 规则

## 开发

- 当前 H5 由 `apps/taro` 构建。页面沿用 Taro、React、TypeScript（TSX）；新增页面放在 `src/pages/`，并在 `src/app.config.ts` 注册。
- 跨端页面优先使用 `@tarojs/components` 和 `@tarojs/taro`。需要浏览器 DOM 或 Web API 时，将相关逻辑限定在 H5 平台分支或 H5 专属模块，并核对其他目标平台的编译结果。
- H5 构建与路由配置在 `apps/taro/config/index.ts` 的 `h5` 节点；开发、生产差异分别在 `config/dev.ts`、`config/prod.ts`。页面 HTML 模板位于 `src/index.html`。
- 当前 H5 使用 browser History 路由和根路径资源地址。新增或修改路由时，核对直接访问、刷新子页面能回退到 `index.html`，且静态资源路径仍按文件路径响应。

## 验证

- 在仓库根目录运行 `pnpm typecheck`、`pnpm lint` 和 `pnpm build:h5`。页面或样式变更还需在目标移动端视口检查实际渲染与交互。
- 涉及浏览器兼容性时，以 `apps/taro/package.json` 的 `browserslist` 和真实目标浏览器为准；构建通过不等于设备兼容。
- `apps/taro/dist/` 由各平台构建共用；检查 H5 产物前，确保最后一次构建是 H5。共享代码变更还需验证受影响的其他平台。
