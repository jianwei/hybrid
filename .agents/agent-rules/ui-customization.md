# UI 定制规则

适用于本项目所有运行平台的界面、组件样式、主题和布局任务；具体组件库及平台能力遵循对应平台规则。

## 定制优先级

- 先检查现有组件和组件库公开 API。按满足需求所需的最小改动选择：组件属性与主题配置 → 平台支持的主题变量或样式令牌 → 局部样式覆盖 → 插槽、组合与包装 → 自定义或替换组件。
- 使用主题变量、CSS 选择器或插槽前，确认目标平台和已安装版本支持该能力；React Native 等平台采用其实际支持的样式机制。
- 自定义或替换组件时，说明现有能力的具体缺口，并保留所需的交互、无障碍和平台适配行为。
- 优先使用公开扩展接口；复制组件库源码后，记录来源与版本，并在依赖升级时检查该组件是否需要同步。

## 验证

- 核验受影响页面的布局、交互和样式；涉及暗色模式、响应式布局或多语言时，覆盖本次改动涉及的状态。
- 修改共享组件时，明确受影响的平台，并按平台规则验证；以目标平台实际结果说明验证范围。

以上定制优先级提炼自 [Rspress 主题 skill](../skills/rspress-custom-theme/SKILL.md)；Rspress 的具体导入路径、变量与插槽仅按 [Rspress 规则](rspress.md) 使用。
